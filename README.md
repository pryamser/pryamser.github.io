# Ryan — Freelancer Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and JavaScript. Designed for free hosting on GitHub Pages.

## Before publishing
1. Open `index.html`.
2. Find `hello@example.com` and replace it with your real email address.
3. Update the About section and replace the two placeholder project cards with real work when available.
4. Optional: change the page title and description in the `<head>` section.

## Publish with GitHub Pages
1. Create a free account at https://github.com.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. Your website will be available at `https://YOUR-USERNAME.github.io`.

## Customize
- Main content: `index.html`
- Colors, layout, and responsive styles: `style.css`
- Mobile navigation and reveal animations: `script.js`

No build tools or paid hosting are required.
